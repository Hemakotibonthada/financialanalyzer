## User Interactions

### Landing Page Flow
```
1. User lands on /
   ↓
2. Scrolls to read features
   ↓
3. Sees pricing
   ↓
4. Reads testimonials
   ↓
5. Clicks "Get Started"
   ↓
6. Goes to /register
   ↓
7. Creates account
   ↓
8. Redirects to /dashboard
```

### Desktop App Flow
```
1. Launch app
   ↓
2. Landing window shows
   ↓
3. User reads welcome
   ↓
4. Clicks "Launch App"
   ↓
5. Landing closes
   ↓
6. Main app opens
   ↓
7. Dashboard loads
```
