## 📈 Key Metrics Explained

### Prediction Accuracy (94%)
- How often AI predictions match actual outcomes
- Higher = more reliable forecasts
- Based on your historical data

### Confidence Level (80-96%)
- How certain the ML model is about prediction
- 90%+ = Very reliable
- 80-90% = Reliable
- <80% = Use with caution

### Sharpe Ratio (1.2 → 1.8)
- Risk-adjusted return measurement
- Higher = better returns per unit of risk
- 1.8 is excellent (above 1.5 is good)

### Optimization Score (87/100)
- Overall portfolio health rating
- 90+ = Excellent
- 80-90 = Good
- 70-80 = Fair
- <70 = Needs improvement

### Behavior Scores (0-100)
- 90+ = Excellent financial habits
- 75-90 = Good discipline
- 60-75 = Room for improvement
- <60 = Needs attention

## 🆘 Troubleshooting

### Issue: Predictions seem inaccurate
**Solution:**
- Ensure at least 3 months of transaction data
- Update all transactions regularly
- Check data quality (correct categories)
- Wait 24 hours for ML model update

### Issue: No optimization recommendations
**Solution:**
- Add investment holdings to portfolio
- Ensure current prices are updated
- Check if portfolio value > ₹50,000
- Refresh page and wait for calculations

### Issue: Anomalies not showing
**Solution:**
- Need at least 30 days of spending data
- Verify transaction categories are correct
- Check if spending is within normal ranges
- Adjust sensitivity in settings

### Issue: Charts not loading
**Solution:**
- Clear browser cache
- Check internet connection
- Try different browser
- Disable ad blockers temporarily
