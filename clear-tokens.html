Clear Authentication Tokens

Click the button below to clear all authentication tokens and login data.
📋 What will be cleared:
  • Authentication tokens (localStorage & sessionStorage)
  • Token expiry data
  • User data

ℹ️ Why is this needed?

The JWT secret was updated in the backend. All existing tokens were created with the old secret and are now invalid. You need to log in again to get a new valid token.
