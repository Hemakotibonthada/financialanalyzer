## 📥 Installation (Simple 3-Step Process)

### Step 1: Run Installer
- Double-click `FinancialAnalyzerSetup-1.0.0.exe`
- If Windows shows security warning, click "More info" → "Run anyway"

### Step 2: Follow Installation Wizard
1. Click "Next" on welcome screen
2. Accept license agreement
3. Choose installation folder (or keep default)
4. Click "Install"

### Step 3: Launch!
- Check "Run Financial Analyzer" checkbox
- Click "Finish"
- Desktop shortcut will be created automatically ✅

**Total time: 1-2 minutes**

## 🎯 Quick Tips

### System Tray
The app runs in the system tray (bottom-right of screen):
- **Minimize window**: App goes to tray
- **Right-click tray icon**: Quick access menu
- **Click tray icon**: Show/hide window

### Keyboard Shortcuts
- `Ctrl+D` - Dashboard
- `Ctrl+E` - Expenses
- `Ctrl+M` - EMI Tracker
- `Ctrl+L` - Lender Dashboard
- `Ctrl+B` - Bill Reminders
- `F11` - Fullscreen
- `Alt+F4` - Quit

### Navigation
Use the application menu at the top:
- **File** - Settings, Quit
- **View** - All feature screens
- **Features** - Quick actions
- **Help** - Documentation

## ⚙️ Requirements

### System Requirements
- **OS**: Windows 10 or Windows 11 (64-bit)
- **RAM**: 4 GB minimum, 8 GB recommended
- **Storage**: 500 MB free space
- **Screen**: 1024x768 minimum resolution

### Backend Server
⚠️ **Important**: The desktop app requires a backend server to function.

**For now (testing)**:
- Backend must run on your computer
- Address: localhost:5001

**For production use**:
- Contact your administrator for server address
- Or deploy your own backend server

## 🔧 Troubleshooting

### App won't start?

**Check if backend is running**:
1. Backend should be on localhost:5001
2. Contact your IT support if you don't have backend access

### Can't see the window?

**It might be in the system tray**:
1. Look for blue $ icon in taskbar (bottom-right)
2. Click icon to show window

### Login not working?

**Check connection**:
1. Ensure backend server is running
2. Check your internet connection (if using remote backend)
3. Verify credentials

### Desktop shortcut missing?

**Reinstall application**:
1. Uninstall from Control Panel
2. Run installer again
3. Ensure "Create desktop shortcut" is checked

---

## 🗑️ Uninstallation

### Method 1: Control Panel
1. Open Windows Settings
2. Go to Apps → Apps & features
3. Find "Financial Analyzer"
4. Click "Uninstall"

### Method 2: Start Menu
1. Open Start Menu
2. Find "Financial Analyzer" folder
3. Click "Uninstall Financial Analyzer"

**Your data will be removed. Export data before uninstalling if needed.**
